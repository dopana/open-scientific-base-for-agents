# Frontend - Open Scientific Base for AI Agents

React 19 + Rsbuild frontend for the Open Scientific Base, a structured knowledge repository for AI agents. Provides a modern UI for browsing, searching, and viewing scientific knowledge files.

## Tech Stack

- **React 19** - UI framework
- **Rsbuild** - Fast build tool by Rspack team
- **TailwindCSS** - Utility-first CSS framework
- **TypeScript** - Type safety
- **Biome** - Linting and formatting
- **Rstest** - Testing framework

## Features

- Category-based navigation (Physics, Biology, Chemistry, Computer Science, Mathematics)
- Full-text search across knowledge files
- Markdown file viewer with syntax highlighting
- Responsive design with sidebar navigation
- RESTful API integration with Rust backend

## Setup

Install the dependencies:

```bash
bun install
```

## Get started

Start the dev server, and the app will be available at [http://localhost:3000](http://localhost:3000).

```bash
bun run dev
```

Build the app for production:

```bash
bun run build
```

Preview the production build locally:

```bash
bun run preview
```
